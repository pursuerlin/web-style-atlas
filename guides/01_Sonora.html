FROM IMAGE TO INTERFACE

复刻时，哪些留作图，哪些必须写代码？

▧

作为视觉素材

音箱、木纹、编织织物、建筑阴影和家居场景属于图像素材。

⌘

作为网页组件

标题、CTA、四列卡片、材质选项、声学控件、导航和收藏均为可编辑 HTML。

最容易踩的坑：避免在 Hero 左侧叠加纯色硬分栏；避免重复的装饰性小字和过度阴影。
落地原则：先从图里提取干净的背景图，再用 CSS Grid / Flex 组织可编辑内容；SVG 负责可缩放图标、轮廓和曲线。VTracer 更适合扁平插画的矢量化，不适合真实摄影或精细材质照片。
